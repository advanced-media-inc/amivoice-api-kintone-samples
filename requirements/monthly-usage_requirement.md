料金明細表示のプラグイン
概要：HTTP APIでCSVを呼び出しその料金明細をkintoneのUIに表として表示する

１　HTTP API downloadusage

１）curlの仕様は下記

curl -O -J \
  -H "Authorization: Bearer {APIKEY}" \
  "https://acp.amivoice.com/util/api/downloadusage/Ami.{serviceID}/{yyyymm}"

２）kintoneのフォームから {APIKEY} と {serviceID} と {yyyymm} が入力される。
フォーム名はそれぞれ、apikey,serviceid,date
例外：serviceIDの末尾が01で終わる場合、HTTPは下記のようにAmi.がつかない
  "https://acp.amivoice.com/util/api/downloadusage/{serviceID}/{yyyymm}"

４）料金行について
　・料金行は、末尾に01がつくアカウント名だけに表示される。
　・エンジンプランごとに料金はまとめられるが、使用量が無料枠のエンジンプランには、料金行が出ない


５）出力
　料金行は表から削除し、料金のデータとして{エンジンプラン名、料金}のフォーマットでフォームに返す。フォームは表形式で名前はcost_table
　料金行を除いた表は、| YYYYMM | アカウント名 | エンジンプラン名 | 使用量（ms） |までの列のCSVデータとしてフォームに返す。フォームは表形式で名前はquantity_table
