# AmiVoice ユーザー辞書登録アプリ（AmiWordRegES）　導入手順書

## 1. 本書について

本書は、AmiVoice ユーザー辞書登録アプリ（AmiWordRegES）とそのプラグインをkintoneに導入するための手順書です。

このアプリケーションは、kintoneのレコード画面からAmiVoice APIのユーザー辞書を管理するためのプラグインです。以下の機能を提供します：

- エンジンごと、profileIDごとの辞書を取得できる
- 取得した単語をkintoneのテーブル上で編集・追加できる
- 単語一覧をAmiVoiceへ一括登録できる
- 新しいprofileIDへ単語を登録できる

操作UIはレコードの新規作成画面と編集画面に表示されます。レコード詳細画面には表示されません。

## 2. 導入に必要な情報・準備

導入を開始する前に、次の情報を準備してください。

1. AmiVoice APIキー
2. 辞書を登録するエンジン
3. 登録対象のprofileID
4. 登録する単語の表記と読み
5. 必要に応じて単語のクラス

APIキーはAmiVoice APIへの接続にだけ使われます。保存操作の前にプラグインがフィールド値を空にするため、APIキーはkintoneのレコードには保存されません。レコードを開くたびに入力が必要です。

## 3. kintoneアプリの構成と準備

導入するkintoneアプリに必要なフィールドを作成します。以下のフィールドを作成し、**フィールドコードを表のとおりに設定**してください。フィールドコードが異なるとプラグインは動作しません。

| 用途               | フィールドコード | フィールド型                      | 備考                                                                |
| ------------------ | ---------------- | --------------------------------- | ------------------------------------------------------------------- |
| APIキー            | `api_key`        | 文字列（1行）                     | 必須。保存されない                                                  |
| 登録先エンジン     | `engine_name`    | ドロップダウンまたは文字列（1行） | 必須                                                                |
| profileID          | `profile_id`     | 文字列（1行）                     | 必須                                                                |
| サンプリングレート | `sample_rate`    | ドロップダウン                    | ハイブリッドエンジンのみ使用。省略時は16k扱い                       |
| 登録単語一覧       | `word_table`     | テーブル                          | 必須                                                                |
| 表記               | `word_written`   | 文字列（1行）                     | `word_table`内に配置                                                |
| 読み／代替表記     | `word_reading`   | 文字列（1行）                     | `word_table`内に配置。ハイブリッドでは読み、E2Eでは代替表記（任意） |
| クラス             | `word_class`     | ドロップダウン                    | `word_table`内に配置。E2Eエンジンでは未使用                         |
| 単語強調度         | `word_biasing`   | ドロップダウン                    | `word_table`内に配置。E2Eエンジンのみ使用。0〜1の0.1刻み            |

### エンジンのドロップダウン設定

`engine_name`をドロップダウンにする場合は、次の表示名を選択肢に登録してください。プラグインがAmiVoice API用の値へ変換します。

| kintoneの選択肢      | APIへ送信される値    |
| -------------------- | -------------------- |
| 日本語E2E_汎用       | `-a2-ja-general`     |
| 中国語E2E_汎用       | `-a2-zh-general`     |
| 多言語E2E_汎用       | `-a2-multi-general`  |
| 日本語E2E_汎用バッチ | `-a2b-ja-general`    |
| 中国語E2E_汎用バッチ | `-a2b-zh-general`    |
| 多言語E2E_汎用バッチ | `-a2b-multi-general` |
| 会話_汎用            | `-a-general`         |
| 会話_医療            | `-a-medical`         |
| 会話_金融            | `-a-bizfinance`      |
| 会話_保険            | `-a-bizinsurance`    |

英語エンジン（`-a-general-en`）は選択肢に含めないでください。AmiVoiceの英語エンジンはユーザー辞書の単語登録に対応していません。

### サンプリングレートのドロップダウン設定

`sample_rate`には`8k`と`16k`の2つの選択肢を登録してください。ハイブリッドエンジンは8k用と16k用で辞書のプロファイルが別物として扱われます。未選択の場合は16k用として扱われます。E2E系エンジンではこの項目は使用しません。

### クラスのドロップダウン設定

`word_class`には次の選択肢を登録してください。クラスは任意項目です。E2E系エンジンでは使用しません。使えるクラスはエンジンによって異なります（[日本語の言語モデルのクラス名一覧](https://docs.amivoice.com/amivoice-api/manual/engines#japanese-class-name)）。

| 対象エンジン                        | クラス                                                                                                       |
| ----------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| すべてのハイブリッドエンジン        | `固有名詞`、`名前`、`名前(名)`、`駅名`、`会社名`、`部署名`、`役職名`、`記号`、`括弧開き`、`括弧閉じ`、`元号` |
| 会話_汎用、会話_金融、会話_保険のみ | `地名`                                                                                                       |
| 会話_医療のみ                       | `病名`、`薬品名`、`病院名`、`手術名`、`地名_区町村`、`地名_支庁市郡`                                         |

登録先エンジンで使えないクラスを選んだ行は、クラスなしで登録されます（表記と読みは登録されます）。

配布しているテンプレート（`AmiWordRegES.zip`）の`word_class`には、上表のクラスがすべて登録されています。以前のテンプレートで作成したアプリでは`役職名`と会話_医療専用のクラスが登録されていないため、アプリのフォーム設定で選択肢を追加してください。追加しないまま、これらのクラスを含む辞書を`登録単語読み出し`で読み出すと、kintoneが値を受け付けずエラーになります。

### 単語強調度の入力

`word_biasing`はE2E系エンジンでのみ使用します。`0`、`0.1`、`0.2`、…、`0.9`、`1`の11個の選択肢をドロップダウンに登録してください（配布しているテンプレートには登録済みです）。未選択の場合はデフォルトの0.5が適用されます。

`登録単語読み出し`で読み出した単語強調度は、小数第2位以下を切り捨てて0.1刻みの選択肢に合わせます（例：0.25→0.2、0.89→0.8）。AmiVoice側に0.1刻みでない値が登録されている辞書を読み出して`登録`すると、切り捨てた値で登録し直されます。

同じ表記（`word_written`）を複数の行に書いて別々の代替表記を登録する場合、単語強調度は表記ごとに1つだけです。行ごとに違う値を入力しても、テーブルで一番上の行の値（未選択なら0.5）がすべての行に適用されます（[ユーザー辞書の単語の登録](https://docs.amivoice.com/amivoice-api/reference/profilewords/set-profile-words)）。同じ表記の行には同じ単語強調度を入力してください。

## 4. プラグインの導入

アプリケーション全体を機能させるため、プラグインとカスタムスクリプトを導入します。

### 4.1 プラグイン（ami_vocab_{version}.zip）の導入

1. kintoneのシステム管理を開きます。
2. プラグインの管理画面で、[リリースページ](https://github.com/advanced-media-inc/amivoice-api-kintone-samples/releases/latest)から取得した `ami_vocab_{version}.zip` などkintone用にパッケージされたZIPファイルをインストールします。
3. kintoneのアプリ管理画面で対象アプリを開きます。
4. アプリの設定からプラグインを開き、インストールしたプラグインを対象アプリに追加します。
5. アプリを更新します。
6. レコードの新規作成または編集画面を開き、ヘッダーメニュースペースに次のUIが表示されることを確認します。
   - profileID選択
   - `profileID読み出し`
   - `登録単語読み出し`
   - `登録`

このプラグインには個別のプラグイン設定画面はありません。AmiVoice APIキー、エンジン、profileIDは各レコード画面で入力します。

### 4.2 カスタムスクリプト（ami_maskkey.js）の導入

APIキーをマスク表示するため、kintone アプリにカスタムスクリプトを追加します。

1. kintone の管理画面から対象アプリを開きます。
2. アプリの設定画面で「カスタマイズ」を開きます。
3. 「JavaScript および CSS によるカスタマイズ」セクションを確認します。
4. 「JavaScript ファイル」の「ファイルを追加」ボタンをクリックします。
5. `ami_maskkey.js` ファイルをアップロードします。
6. スコープを「デスクトップ」に設定します。
7. アプリを更新して設定を反映します。

このスクリプトにより、フォーム画面での API キー入力欄がマスク表示（パスワード形式）となり、セキュリティが向上します。

## 5. 運用・使用方法

### 5.1 新しいprofileIDへ登録する

1. レコードの新規作成画面を開きます。
2. `api_key`にAmiVoice APIキーを入力します。
3. `engine_name`で登録先エンジンを選択します。
4. `profile_id`にprofileIDを入力します。
   - 使用できる文字は半角英数字、ハイフン（`-`）、アンダースコア（`_`）です。
5. ハイブリッドエンジンの場合は`sample_rate`で対象の音声のサンプリングレート（8k/16k）を選択します。
   - 未選択の場合は16k用のプロファイルが対象になります。電話録音など8kの音声を認識させる場合は必ず選択してください。
6. `word_table`に単語を入力します。
   - ハイブリッドエンジンの場合、表記と読みは両方入力してください。
   - E2E系エンジンの場合、表記は必須、代替表記（`word_reading`。カタカナでの入力を推奨）と単語強調度（`word_biasing`、0〜1の0.1刻みから選択）は任意です。省略時の単語強調度は0.5です。
   - クラスはハイブリッドエンジンで必要な場合だけ選択してください（E2E系エンジンでは未使用）。
   - 完全な空行は登録対象から除外されます。
7. `登録`を押します。
8. ステータスメッセージで登録件数を確認します。

### 5.2 既存の辞書を編集・追記する

1. レコードの新規作成または編集画面を開きます。
2. `api_key`にAmiVoice APIキーを入力します。
3. `engine_name`で対象エンジンを選択します。
4. `profileID読み出し`を押します。
5. profileID選択欄から対象のprofileIDを選びます。
   - 選択値は自動的に`profile_id`へ反映されます。
6. `登録単語読み出し`を押します。
7. テーブルの単語を編集または追記します。
8. `登録`を押します。

## 6. 注意事項・トラブルシューティング

### 6.1 運用上の重要な注意事項

#### 登録は辞書全体の再登録です

`登録単語読み出し`で取得した単語を編集した後に`登録`を押すと、テーブルに残っている単語一覧が対象profileIDへ送信されます。既存単語に追記する場合は、先に必ず読み出し、削除したくない単語をテーブルに残してください。

テーブルが空（登録対象0件）のまま`登録`を押すと、対象profileIDの登録済み単語がすべて削除されるため、確認ダイアログが表示されます。削除しない場合は「キャンセル」を選んでください。

#### APIキーは保存されません

レコード保存時に`api_key`は空文字へ変更されます。APIキーを入力した画面で登録処理を行った後、レコード保存を実行することはできますが、次回利用時は再入力してください。

#### E2E系エンジンではクラスを送信せず、単語強調度が使えます

接続エンジン名が`-a2`で始まるE2E系エンジンでは、`word_written`を表記（`written`）、`word_reading`を代替表記（`alternativewritten`）として送信します。入力したクラスは登録リクエストに含まれません。`word_biasing`で0〜1の値を選択すると単語強調度（`biasing`）として送信され、省略時はAmiVoice側のデフォルト（0.5）が適用されます。

代替表記は、認識結果の候補に出やすくしたうえで表記に置き換える文字列です。表記の読みのように使うこともできますが、ハイブリッドエンジンの「読み」とは性質が異なります。日本語のE2Eエンジンでは固有名詞の認識候補がカタカナで出やすいため、代替表記はひらがなではなくカタカナで入力すると効果が出やすくなります（例：表記「絶滅哺乳類」、代替表記「パレオパラドキシア」）。詳しくは[End to Endエンジンの単語強調](https://docs.amivoice.com/amivoice-api/manual/user-dictionary-basics-e2e)を参照してください。

登録APIは辞書を丸ごと置き換えるため、読み出した単語をそのまま再登録すると、読み出し時に取得した単語強調度（小数第2位以下を切り捨てた値）で登録されます。単語強調度を未選択のまま再登録すると、次回以降デフォルト値（0.5）に戻る点に注意してください。

#### ハイブリッドエンジンは8k/16kでプロファイルが別物です

`sample_rate`を指定しない場合、API呼び出しは16k用のプロファイルを対象とします。8k音声（電話録音など）用の辞書を操作する場合は、必ず`sample_rate`に`8k`を選択してください。

#### APIキーの権限と通信

通信先は`https://acp-api.amivoice.com`です。APIキーはBearerトークンとして送信されます。APIキーは他の利用者に共有せず、必要な権限が付与されたキーを使用してください。

### 6.2 エラーが出たとき

| 表示・症状                                 | 確認すること                                                                                                                                                                                          |
| ------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| APIキーを入力してください                  | `api_key`にキーを入力したか確認する                                                                                                                                                                   |
| 登録先エンジンを選択してください           | `engine_name`を入力・選択する                                                                                                                                                                         |
| profileIDを入力または選択してください      | `profile_id`を入力するか、profileIDを選択する                                                                                                                                                         |
| profileIDの形式エラー                      | 半角英数字、`-`、`_`だけにする                                                                                                                                                                        |
| 表記と読みは両方入力してください           | ハイブリッドエンジンでテーブル内の片方だけ入力された行を修正する                                                                                                                                      |
| 表記を入力してください                     | E2E系エンジンで表記が未入力の行を修正する                                                                                                                                                             |
| 単語強調度は0から1の数値で入力してください | `word_biasing`に0〜1の数値以外が入力されていないか確認する                                                                                                                                            |
| profileIDが取得できない                    | APIキー、エンジン、AmiVoice側のprofileID権限、ネットワークを確認する                                                                                                                                  |
| 単語が読み出されない                       | 対象エンジンとprofileID、`sample_rate`（8k/16k）の組み合わせを確認する                                                                                                                                |
| event.record...word_class.value が不正です | 読み出した単語のクラスが`word_class`の選択肢（3章「クラスのドロップダウン設定」）にないため、空欄として読み込まれる。エンジン側のクラス一覧と`word_class`の選択肢を合わせるか、そのまま空欄で運用する |
| 画面にボタンが表示されない                 | レコードの新規作成・編集画面であること、フィールドコード、プラグイン追加後のアプリ更新を確認する                                                                                                      |

APIからHTTPエラーが返った場合は、画面にHTTPステータスとレスポンス内容が表示されます。入力を修正して再実行してください。
