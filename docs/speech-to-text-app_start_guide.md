# AmiVoice  Speech to Textアプリ スタートガイド

## 1. このリソースでできること

AmiVoice API を使って kintone のレコードに添付した音声ファイルを文字起こしするための、次のリソースを使います。いずれも[リリースページ](https://github.com/advanced-media-inc/amivoice-api-kintone-samples/releases/latest)から取得できます。

- kintone アプリテンプレート: `AmiSimpleES.zip`
- kintone プラグイン本体: `ami_stt_{version}.zip`　（{version}はプラグインバージョン）

レコードの保存後、レコード詳細画面を開くとプラグインが音声ファイルを取得し、AmiVoice API へ送信します。認識結果、API レスポンス、処理状態を同じレコードへ保存します。

## 2. 前提条件

- kintone 環境でアプリテンプレートを読み込める権限があること
- アプリにプラグインを追加・設定できる権限があること
- AmiVoice API の API キーが発行済みであること

## 3. アプリを作成する

1. kintone のアプリ管理から「アプリを作成」を開きます。
2. 「テンプレートファイルを読み込んで作成」を選択します。
3. AmiSimpleES.zip を読み込みます。
4. 作成されたアプリを保存・公開します。

テンプレートには、次のフィールドが定義されています。

| 表示名           | フィールドコード    | 種類             | 用途                            |
| ---------------- | ------------------- | ---------------- | ------------------------------- |
| audio_file       | `audioFieldCode`    | 添付ファイル     | 文字起こし対象の音声            |
| engine_selection | `ドロップダウン`    | ドロップダウン   | 認識エンジンの選択              |
| profileID        | `profile_id`        | 文字列（1行）    | ユーザー辞書のプロファイルID    |
| amivoice_result  | `resultFieldCode`   | 文字列（複数行） | AmiVoice の `text`              |
| post_response    | `responseFieldCode` | 文字列（複数行） | HTTP ステータスとレスポンス本文 |
| status           | `statusFieldCode`   | 文字列（1行）    | 処理中、完了、エラーの補助表示  |

プラグインは、フィールドコードに含まれる文字列（`result`、`response`、`status`）やフィールドの種類（添付ファイル、ドロップダウン）で出力先・入力元を判定します。フィールドコードを変更すると正しく判定できなくなる場合があるため、テンプレートのまま使用してください。

使用量集計タグ（`billing_key`）を使う場合は、フィールドコード `billing_key` の文字列（1行）フィールドをアプリに追加してください（テンプレートには含まれていません）。入力した値は、AmiVoice API の利用明細で使用量を集計する単位として使われます。

「profileID」（`profile_id`）に値を入力すると、辞書管理アプリ（[vocabulary-management-app](./vocabulary-management-app_start_guide.md)）で登録した単語が文字起こしに反映されます。ハイブリッドエンジンで 8k/16k 両方に対応するエンジンの場合、同じ接続エンジン名でも 8k 用と 16k 用でプロファイルが分かれるため、辞書管理アプリで単語を登録したときと同じサンプリングレートの音声でなければ辞書は反映されません。


## 4. プラグインを追加・設定する

### プラグインを追加する

1. kintone のシステム管理またはアプリ設定で「プラグイン」を開きます。
2. [リリースページ](https://github.com/advanced-media-inc/amivoice-api-kintone-samples/releases/latest)から取得した `ami_stt_{version}.zip` ファイルを読み込みます。
3. 対象アプリのプラグイン一覧で AmiVoice STT Node を追加します。
4. プラグインを有効にして保存します。
5. アプリを更新します。

### プラグインを設定する

対象アプリのプラグイン設定画面では、AmiVoice API キーを入力して保存します。

| 設定項目         | 設定内容                       |
| ---------------- | ------------------------------ |
| AmiVoice API Key | AmiVoice API の API キー。必須 |

API キーは `kintone.plugin.app.setProxyConfig` でプラグインに保存され、AmiVoice API（`https://acp-api.amivoice.com/v1/recognize`）へ送信するときに kintone が `Authorization` ヘッダーとして付加します。アプリの利用者がブラウザーから API キーを読み取ることはできません。

- 設定済みの API キーは設定画面に表示されません。変更するときだけ入力してください。空欄のまま保存すると、設定済みのキーがそのまま使われます。
- 以前のバージョンから更新した場合は、プラグイン設定画面を開いて「保存」を押してください。旧バージョンで保存した API キーが新しい保存先へ移り、旧保存先からは削除されます。保存するまでは「API key missing」と表示され、文字起こしは実行されません。

## 5. 基本的な使い方

1. アプリで新規レコードを作成します。
2. 「audio_file」に音声ファイルを添付します。
3. 必要に応じて「engine_selection」で認識エンジンを選択します。
4. 辞書を使う場合は「profileID」に、辞書管理アプリで登録したprofileIDを入力します。エンジンと8k/16kの組み合わせが一致していないと辞書は反映されません。使える文字は半角英数字、`-`、`_` です（`__` で始まるIDは使用できません）。それ以外の文字を含む場合はエラーになります。
5. レコードを保存します。
6. 保存後に表示されるレコード詳細画面で処理が開始されます。
7. 処理完了後、画面が再読み込みされ、「amivoice_result」と「post_response」に結果が表示されます。

処理対象は、音声ファイルが添付されていて、まだ認識結果がないレコードです。新規・編集保存後にキューへ登録し、詳細画面で実行します。詳細画面を直接開いた場合も条件を満たせば自動実行されます。

処理に失敗すると、「post_response」に `ERROR: ` で始まるエラー内容が、「status」に「エラー」が保存されます。失敗したレコードは詳細画面を開いても自動では再実行されません。音声ファイルや設定など原因を修正してからレコードを編集・保存すると再実行されます。

### 対応している音声ファイル形式

AmiVoice API が受け付けるのは次の形式です。

- WAV
- Ogg
- MP3
- FLAC
- WebM（Opus）

`m4a`・`aac` は AmiVoice API が対応していない形式です。また、ヘッダーなしPCMは音声フォーマット（`c` パラメータ）の指定が必要ですが、本プラグインは指定しないため利用できません。これらのファイルを添付すると、文字起こしに失敗します。

### ログ保存・音声サイズの制限

- 本プラグインはログ保存ありのエンドポイント（`/v1/recognize`）を使用します。音声データと認識結果は AmiVoice API 側に保存されます。ログを残したくない場合は、現状コードの変更が必要です。
- 同期HTTPで送信できる音声データは最大 16,777,215 バイトです。本プラグインは送信前に添付ファイルのサイズを確認し、超過する場合は AmiVoice API へ送信せずエラーにします。長い音声は非同期HTTPの利用を検討してください。
- 複数行テキストの項目（「amivoice_result」、「post_response」）に保存する内容が 65,535 文字を超える場合は、末尾を切り詰めて `...(truncated)` を付けて保存します。
- 音声のダウンロードと認識リクエストにはそれぞれ60秒のタイムアウトが設定されています。大きな音声ファイルや回線状況によってはタイムアウトする場合があります。

## 6. 認識エンジン

テンプレートの選択肢は次の AmiVoice API パラメータへ変換されます。選択肢の表示名が下表と一致しない場合はエンジンを推測せずエラーにします。エンジンが未選択の場合は `-a-general` を使用します。

| 表示値             | API パラメータ       |
| ------------------ | -------------------- |
| 会話汎用           | `-a-general`         |
| 英語汎用           | `-a-general-en`      |
| 医療               | `-a-medical`         |
| E2E日本語_速度優先 | `-a2-ja-general`     |
| E2E多言語_速度優先 | `-a2-multi-general`  |
| E2E日本語_精度優先 | `-a2b-ja-general`    |
| E2E多言語_精度優先 | `-a2b-multi-general` |
